brand/
--------------

These images are core parts of the project, if replacing them changes how the project feels then they are part of this project's "brand".

What goes here:
  - avatar / identity
  - banner
  - any UI artwork (mode toggle art, icons that aren't from the symbol font)
  - icons

What does NOT go here:
  - project screenshots and thumbnails  ->  assets/projects/
  - anything tied to one card or one section

The avatar.jpg is stripped directly from a concept art, specifically from [this](https://www.reddit.com/r/WutheringWaves/comments/1fnsv83/the_highest_quality_jinhsi_satoru_concept_art/) reddit post.


Any icons here **do not mean I am claiming to be them**, they are here for the fact that they change of it feels if they are changed. After reading their brand pages and downloading them, all of these images are allowed for use like this.
