projects/
--------------

Images belonging to objects in the projects category.

What goes here:
  - card thumbnails
  - screenshots shown in the detail sheet
  - a project's own logo or icon

What does NOT go here:
  - avatar, banner, UI artwork  ->  assets/brand/

Naming: match the project, lowercase, hyphens for spaces.
  extended-bio-thumb.webp
  extended-bio-01.webp

Prefer .webp. Smaller than .png or .jpg at the same quality, and every
browser that matters supports it.
